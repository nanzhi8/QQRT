# QQRT · 使用文档

> 手表端版本 **v4.11.13**（包名 `com.qqrt.band`）
> 适用设备：小米手环 9 Pro / 10 Pro（336×480）、红米手表 6、Xiaomi Watch S5（480×480 圆屏 / eSIM）
> 服务端部署见另一篇《QQRT · 服务端部署方法与软件原理》

---

## 一、开始之前

| 你需要 | 说明 |
|---|---|
| 一台手环 | 系统为 Vela，屏幕 336×480 |
| 一个 QQRT 服务端 | 自己部署或用别人给的地址，形如 `https://qqrt.example.com` |
| 服务端账号密码 | 注意：**是服务端网站的账号，不是 QQ 账号** |

安装方式二选一：

- **AstroBox**：搜索「QQRT」→ 安装（推荐，能收到更新）
- **调试器**：`aiot install` 或快应用调试器扫码安装 `com.qqrt.band.release.4.11.0.rpk`

## 二、登录

1. 打开 QQRT，进入登录页；
2. **服务器地址**：填域名即可，`https://` 会自动补；粘贴完整网址也能自动解析；
3. **账号 / 密码**：服务端网站的内部账号；
4. 点「登 录」。

> 登录成功后凭证会存在手表本地，下次打开直接进会话列表。想换账号：设置 → 退出登录。

---

### 2.1 账号：注册、改密码、查看机器人绑定

**自助注册**（默认开启）：控制台登录页下方点「没有账号？自助注册 / 账号管理 →」，或访问 `/adduser`。填用户名和密码即可创建账号，注册后自动登录，随后可以在控制台绑定**自己的** QQ 机器人（AppID/AppSecret、消息、会话全部按账号隔离）。

管理员可在「账号管理」页关闭自助注册；关闭后只能由管理员手动添加账号。

**修改密码**：账号管理页「修改我的密码」，需要验证旧密码。管理员还可以用「重置用户密码」直接重置任意账号（不需要旧密码）。

**查看绑定情况**（仅管理员）：用户列表里每个账号会显示

- `已绑定 机器人昵称 · 在线 / 离线`（并显示掩码后的 AppID）
- 或 `未绑定机器人`

只展示掩码 AppID，**不返回 AppSecret**。

| 接口 | 说明 |
|---|---|
| `POST /api/auth/signup` | 自助注册，返回 token 并自动登录 |
| `GET /api/auth/signup` | 查询自助注册是否开放 |
| `POST /api/admin/signup` | 管理员开关自助注册 |
| `POST /api/auth/password` | 改自己的密码（需旧密码） |
| `POST /api/admin/users/password` | 管理员重置用户密码 |
| `GET /api/admin/users` | 用户列表 + 每个账号的机器人绑定状态 |

> **部署提醒**：托管沙箱重新发布会重建运行环境，PGlite 数据目录可能变成空库。如果 `/api/admin/status` 返回 `initialized: false`，打开 `/adduser` 重新设置一次管理员密码即可；已绑定的机器人凭据也需要重新填。服务端启动时会自动幂等建表（`ensureSchema`），不会再出现「users 表不存在」的报错。

## 四、聊天

### 4.1 界面构成

```
┌──────────────────────────────┐
│ ‹        老王         刷新    │  顶栏
├──────────────────────────────┤
│        ┌────────────┐        │
│        │ 真的，刚试过 │        │  自己：右侧蓝色
│        └────────────┘        │
│ ┌────────────┐               │
│ │ 那挺好      │               │  对方：左侧灰色
│ └────────────┘               │
├──────────────────────────────┤
│ ☺ │ 点此输入消息 │    发送    │  输入栏
└──────────────────────────────┘
```

- 顶栏点标题 → 群成员列表（群聊时）；长按标题 → 改会话名
- 点「刷新」手动拉一次新消息

### 4.2 群聊显示发送人（v4.11.0 新增）

群聊里，别人的消息会在气泡**上方**多一行灰色小字，写着发送人昵称：

```
  ┌──────────────┐
  │ 老王          │   ← 16px 灰色昵称
  │ ┌──────────┐ │
  │ │ 晚上打游戏？│ │
  │ └──────────┘ │
  └──────────────┘
```

| 场景 | 是否显示昵称 |
|---|---|
| 群聊 · 别人发言 | ✅ 显示 |
| 群聊 · 同一个人连续发多条 | ⚠️ 只在**第一条**显示，避免刷屏 |
| 群聊 · 自己发言 | ❌ 不显示 |
| 好友单聊 | ❌ 不显示 |

> 昵称来自服务端返回的 `senderName`，超过 12 个字会截断。

### 4.3 表情以图片显示（v4.11.0 新增）

手环系统字体**没有 emoji 字形**，直接把 emoji 字符画出来只会得到一个方块。所以 QQRT 用内置的表情图片来画：

| 消息里是 | 显示成 |
|---|---|
| `[微笑]` 这类 QQ 表情码（内置 75 个常用表情） | 对应的表情图 |
| 🙂 这类真 emoji 字符（QQ 转发过来时是字符） | 有对应图就画图 |
| **对方发的表情包 / 图片消息** | **直接把图片画在气泡里**（最大 150×150，按原图比例缩放） |
| 没有内置图的 emoji | **直接隐藏**（不显示方块） |
| 一条消息超过 6 个表情码 | 只画前 6 个 |

**发表情**：点输入栏左侧的笑脸按钮 → 弹出表情面板（24 个，4 行 × 6 列）→ 点一下插入输入框 → 点「发送」。

**看大图**：长按气泡 → 查看大图，进入全屏。

> 表情在输入框里显示为 `[微笑]` 这样的文字码，发送后对方收到的是表情。
>
> 图片消息的宽高由服务端在入库后异步探测（只读文件头，不下载整图）并回填；探测失败时手表端退回 1:1 方框显示。

### 4.4 查看被回复的消息（v4.11.0 新增）

聊天里凡是「引用回复」的消息，气泡内会多出一条引用条：

```
  ┌────────────────────────┐
  │▎老王：晚上打游戏？        │  ← 引用条，左侧蓝线
  │  好啊，几点             │
  └────────────────────────┘
```

| 操作 | 效果 |
|---|---|
| **点引用条** | 列表自动滚到被引用的那条消息，并**高亮闪 1.5 秒** |
| 长按气泡 → 查看原消息 | 同上（菜单里也有入口） |
| 原消息不在已加载范围 | 提示「原消息不在当前列表」 |

> 自己发出的引用回复带原消息 id，能精确跳转；QQ 里别人引用某条消息时平台不给 id，手表按「引用文字 + 发送人」在已加载消息里找最接近的一条，找不到就提示。

### 4.5 长按气泡

| 菜单项 | 说明 |
|---|---|
| 查看原消息 | 有引用的消息才有，跳到被引用的那条 |
| 查看大图 | 图片 / 表情包消息才有，进入全屏查看 |
| 引用回复 | 输入栏上方出现引用条，发送时带上原消息 |
| @ 发送者 | 群聊里快速 @ 这个人（自动填 `@昵称 `） |
| 撤回 | 只有自己发的、且时间允许时才出现 |
| 重发 | 发送失败的消息重新发 |
| 删除 | 只删手表本地的这条记录 |

## 五、群管理（v4.11.0 新增）

> 前提：机器人在该群必须是**管理员**，否则 QQ 侧会拒绝（手表提示「该群未开放此操作」）。

### 5.1 成员操作

群聊里点标题进「群成员」列表，**长按某个人**弹出操作面板：

| 操作 | 说明 |
|---|---|
| @ TA | 回到聊天并填入 `@昵称 ` |
| 禁言 10 分钟 / 1 小时 / 1 天 | 对该成员禁言指定时长 |
| 解除禁言 | 立即解除 |
| 移出群聊 | 踢出该群（不可撤销，请确认） |

### 5.2 @全体成员

群聊输入栏左侧多一个「@全体」按钮，点一下变成 `@全体 ✓`，再发送即生效：

- 需要机器人是**群管理员**
- 官方限制：**每个群每天只能 @ 全体 1 次**
- 消息里会出现 `@全体成员`，所有群成员收到提醒

### 5.3 群管理怎么用（v4.11.3 起改为分组）

群聊顶栏点「**管理**」进入。首页只显示 5 个分类，点进去才是具体操作，不用记任何 ID。

| 分类 | 里面有什么 |
|---|---|
| **看看这个群** | 群资料、机器人在这里的权限、本群编号 |
| **管群成员** | 选一个成员 / 看名单 / 禁言 10 分钟 / 解除禁言 / 移出群聊 / 移出并拉黑 / 看黑名单 / 加入黑名单 / 移出黑名单 |
| **谁要进群** | 看申请列表、同意一个人、拒绝一个人 |
| **自动放人进群** | 看现有规则、开启自动同意、停用规则、删除规则 |
| **发按钮消息** | 发投票、发签到、发审批按钮 |

**三个关键交互**：

1. **不用填 openid**：先点「管群成员 → 选一个成员」，从名单里点一个人，顶部会显示「成员：张三」，之后禁言 / 移出都直接对他生效。
2. **不用填规则 ID**：停用 / 删除规则时，会自动列出规则让你点一条。
3. **危险操作要确认**：移出群聊、拉黑、删除规则会先显示「要执行 / 对象 / 确认执行」，点「确认执行」才真的做。

结果页会把人话翻译出来（`member_role: admin` → `身份: 管理员`）。如果失败，会直接告诉你原因：

- 「这个接口要向 QQ 平台申请白名单」→ 邮箱 `qq_open@tencent.com` 申请
- 「机器人不是群管理员」→ 在 QQ 群里把机器人设为管理员

> 现在一定能用：看群编号、发按钮消息、禁言（机器人是管理员时）。其余多数接口需要 **11253 白名单**。

### 5.4 按钮消息与系统提示（v4.11.0 新增）

**按钮消息**：群管理页最下面三个菜单——`发起投票` / `发起签到` / `发起审批`，点一下会往群里发一条带按钮的消息。

- QQ 端的人点按钮 → 服务端收到 `INTERACTION_CREATE` → 自动回 `PUT /interactions/{id}` 确认 → 聊天里出现一条居中灰字「XXX 点击了【同意】」
- 手表端也能直接点自己消息里的按钮（蓝色小胶囊），点了同样会留一条提示
- 按钮数据格式 `动作:值`（如 `vote:A`、`approve:yes`），方便后续扩展业务动作

**系统提示事件**（补全了官方事件，全部变成聊天里的一条灰字）：

| 事件 | 提示 |
|---|---|
| 好友删除 | 对方已删除好友 |
| 成员加入 / 退出群 | 有新成员加入群聊 / 有成员退出了群聊 |
| 单聊 / 群消息接收关闭或开启 | 对方（或群内）关闭/开启了消息接收 |
| 订阅消息授权状态变更 | 已允许 / 已拒绝订阅消息 |
| 按钮交互回调 | XXX 点击了【按钮名】 |

> 这些事件需要额外 intent（`1<<24` 群成员事件、`1<<26` 交互事件）。**默认不开启**，因为机器人没在平台开通对应权限时，网关会直接断开连接（4914/4915）。开通后在 `.env` 里设 `QQRT_EXTRA_EVENTS=1` 并重启服务端。

### 5.6 获取 openid（群管理参数怎么填）

群管理页里不少菜单要填 `openid` / `策略 ID`，不用手打，按下面取：

| 要填的值 | 从哪里拿 |
|---|---|
| **群 openid** | 群管理页第一条「本群 ID（openid）」；也就是会话 ID `group:xxxx` 冒号后面那串 |
| **成员 openid / 你自己的** | 群管理页第二条「选择成员取 openid」→ 点一个人自动填入参数；对应官方 `GET /v2/groups/{g}/members` 的 `member_openid` |
| **机器人自己的 openid** | 「机器人群内状态」→ `member_openid`；`GET /v2/groups/{g}/bot_state` |
| **入群申请人 openid** | 「入群申请列表」→ 结果里长按对应那行填入参数；`GET /v2/groups/{g}/join_request_list` |
| **自动审批策略 ID** | 「自动审批策略列表」→ `strategy_id`，长按填参数；`GET /v2/groups/join_approval_strategy` |

> 任何结果行**长按**都能把该行的值填进「参数」；点右上角「参数」可手动改。填好后再点「禁言 / 移出 / 审批」等菜单就直接带上，不用重复输入。

服务端直接查（带手表登录后的 token）：

```bash
curl -X POST "https://<你的域名>/api/watch/group/api" \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"action":"members","conversationId":"group:<群openid>"}'
```

或直接调官方接口（用机器人 AccessToken）：

```bash
curl "https://api.bot.qq.com/v2/groups/<群openid>/members" \
  -H "Authorization: QQBot <access_token>"
```

**注意事项**
- openid 是**按 AppID 隔离**的：换机器人 AppID 后，所有 openid 都会变，之前填的参数要重新取
- openid ≠ QQ 号；自动审批白名单用的是 QQ 号字符串，不是 openid
- 好友（单聊）的 openid 来自入站消息的 `senderId`；给机器人发一条消息，服务端就会记下你的 openid
- 官方成员列表接口带 11253 白名单限制；没开通时「选择成员」走本地缓存（发过言的人），名单可能不全

### 5.7 说明

QQ 开放平台对群管理接口有频率限制（30–60 QPM）和单次 ≤20 人、禁言 ≤30 天的约束，QQRT 已在服务端做了参数上限保护。

## 六、输入法

点输入框 → 全屏键盘：

- **全键盘（QWERTY）**：拼音输入，带候选词行；可切英文、数字、符号页
- **T9 九宫格**：小屏更好按
- 点输入行 = 确认并把文字回填到聊天输入框；按返回键 = 取消本次输入

> 输入结果只回填到聊天输入框，不会直接发送——确认无误再点「发送」。

## 八、常见问题

**Q：登录提示网络错误 / 一直转圈**
1. 确认地址能从手机浏览器打开（`https://你的域名`）；
2. 服务端是否在运行（`docker ps` 或看日志）；
3. 证书是否是受信任的 HTTPS——手环不认自签名证书。

**Q：消息不更新**
- 点顶栏「刷新」；还不行就 设置 → 重置同步进度。
- 轮询间隔 3.2 秒，刚发完消息最多等 3 秒才看到对方的回复是正常的。

**Q：表情显示不出来 / 变成方块**
- v4.11.0 起，没有内置图的 emoji 会被**隐藏**而不是显示方块；
- 如果整条消息都消失了，说明里面全是未收录的 emoji，可以让我们补图（见下方「扩展表情」）。

**Q：群聊看不到昵称**
- 只有**群聊**里**别人**的消息才显示；
- 服务端需要在消息里返回 `senderName`，没有的话手表端拿不到名字。

**Q：安装失败**
- 检查 rpk 是否与手环型号匹配（只支持 watch 类型）；
- 版本号必须比已安装的高（当前 4.11.0 / versionCode 81）。

## 九、扩展表情（给开发者）

表情图放在 `src/common/emoji/`，文件名是 emoji 的 Unicode 码点（小写十六进制），例如 `1f642.png` 对应 🙂。当前内置 **75 个**常用 QQ 表情（来自 emoji-datasource-twitter 的 64px 图，生成脚本：`tools/gen-qq-emoji.cjs`）。

新增一个表情：

1. 把 PNG（建议 60×60，透明底）放进 `src/common/emoji/`；
2. 在 `src/common/api.js` 的 `EMOJI_CP`（表情码 → 码点）和 `EMOJI_IMG`（表情码 → 图片路径）里各加一行；
3. 重新 `aiot build`。

`splitRich()` 会自动处理「表情码」和「真 emoji 字符」两种来源，不需要改渲染逻辑。
